# LUV-88 빵굽기 개편 이미지: GPT 프롬프트

작성: 2026-10-29. 대상 목록과 결정 사항은 `docs/bread-baking-shaping-assets.md` 를 본다.

## 사용법

- 진행 중인 GPT 대화에 **0번(공통 스타일)을 먼저** 넣고, 1번부터 한 장씩 요청한다.
- 가능하면 기존 에셋을 스타일 참고로 같이 첨부한다: `src/assets/images/bread-baking/originals/` 의 `board.png`, `dough.png`, `flat-dough.png`, `salt-bread.png`, `oven.png`, `empty-bowl.png`.
- 반죽 이미지(2~7번)는 **같은 대화에서 연달아** 만들어야 시점·크기가 맞는다.
- 받은 이미지는 배경 투명 여부를 확인하고, 아니면 `docs/bread-baking-background-removal.json` 절차로 배경을 제거한다.

## 0. 공통 스타일 (먼저 한 번)

```
지금부터 모바일 게임 "빵굽기 미니게임"에 들어갈 이미지 에셋을 한 장씩 만들 거야.
반드시 기존 디자인의 스타일을 그대로 유지해야 해. 새로운 화풍을 만들지 말고, 첨부한(또는 앞에서 만든) 기존 에셋과 같은 세트처럼 보여야 해.

기존 스타일:
- 귀엽고 부드러운 캐주얼 일러스트, 매끈하게 칠한 반광택 렌더링
- 크림·베이지·연갈색 + 연분홍 포인트 색감, 채도 낮은 파스텔 톤
- 부드러운 그림자와 은은한 하이라이트, 외곽선은 얇고 진하지 않게
- 소품은 정면에서 살짝 위로 내려다보는 시점
- 귀여운 디테일(분홍 하트, 둥근 모서리) 정도만, 과한 장식 금지

공통 규칙:
- 배경은 완전히 투명한 PNG
- 대상 하나만, 캔버스 가운데에 여백을 조금 두고 배치
- 글자, 숫자, 로고, 워터마크, 테두리 프레임, 바닥 그림자 판 넣지 않기
- 같은 세트의 이미지끼리는 시점, 조명 방향(왼쪽 위), 크기 비율을 통일
```

## 1. 큰 도마

```
기존 디자인 스타일을 유지해서 "큰 나무 도마"를 그려줘.
- 반죽을 밀고 성형하는 작업대로 쓰는 넓은 도마. 화면 아래쪽을 크게 채울 거라 가로로 넓은 직사각형(가로:세로 약 4:3), 모서리는 둥글게
- 정면에서 살짝 내려다보는 시점. 윗면이 넓게 보여야 하고, 그 위에 반죽을 올릴 거라 윗면은 비워 둬
- 연한 나무색, 은은한 나뭇결, 기존 도마(첨부)와 같은 색감과 질감
- 손잡이는 없어도 되고, 있다면 작게
- 투명 배경 PNG, 정사각형 캔버스에 도마만
```

## 2. 둥근 반죽 (큰 도마용)

```
기존 디자인 스타일을 유지해서 "둥근 빵 반죽 한 덩이"를 그려줘.
- 1번 도마 위에 올라갈 반죽. 1번 도마와 같은 시점과 조명
- 매끈하고 말랑해 보이는 크림색 반죽, 살짝 납작한 둥근 덩어리
- 기존 반죽 이미지(첨부)와 같은 색감
- 투명 배경 PNG, 정사각형 캔버스 가운데. 도마는 그리지 말고 반죽만
```

## 3. 밀대로 편 반죽

```
기존 디자인 스타일을 유지해서, 2번 반죽을 밀대로 밀어 편 모양을 그려줘.
- 소금빵 성형 직전 반죽: 한쪽은 넓고 반대쪽으로 갈수록 가늘어지는 길쭉한 물방울(삼각형) 모양, 얇고 평평하게
- 2번과 같은 시점, 같은 조명, 같은 색감. 캔버스 크기도 2번과 동일하게
- 투명 배경 PNG, 반죽만
```

## 4~6. 성형 진행 3장 (같은 대화에서 연달아)

```
기존 디자인 스타일을 유지해서, 3번 반죽을 소금빵 모양으로 말아 가는 과정을 3장으로 그려줘. 한 장씩 따로 만들어줘.
- 넓은 쪽 끝에 작은 버터 조각을 올리고, 넓은 쪽부터 가는 쪽으로 돌돌 말아 간다
- 4번: 넓은 쪽 끝에 버터가 올라가 있고 막 말기 시작한 모습
- 5번: 반쯤 말린 모습
- 6번: 거의 다 말리고 끝부분만 조금 남은 모습
- 3장 모두 3번과 같은 시점, 같은 조명, 같은 캔버스 크기, 같은 위치(가운데)
- 투명 배경 PNG, 반죽만
```

## 7. 성형 완료 반죽 (굽기 전)

```
기존 디자인 스타일을 유지해서, 다 말아 완성한 "굽기 전 소금빵 반죽"을 그려줘.
- 돌돌 말린 소금빵(작은 크루아상처럼 겹이 보이는 통통한 모양), 아직 굽지 않아 연한 크림색
- 기존 소금빵 반죽 이미지(첨부 salt-bread)와 같은 모양과 색감, 시점은 4~6번과 동일
- 투명 배경 PNG, 반죽만
```

## 8. 소금 뿌린 성형 반죽

```
기존 디자인 스타일을 유지해서, 7번 반죽 위에 굵은 소금 알갱이를 뿌린 모습을 그려줘.
- 7번과 모양, 크기, 시점, 위치를 완전히 같게 하고 소금만 추가
- 소금은 하얗고 반짝이는 굵은 알갱이, 윗면에 적당히 흩뿌림
- 투명 배경 PNG
```

> 기존 `salt-bread.png`에 소금이 이미 보이면 7·8번 중 하나는 생략할 수 있다.

## 9. 화살표

```
기존 디자인 스타일을 유지해서, 화면에 띄울 "방향 안내 화살표" 하나를 그려줘.
- 오른쪽을 가리키는 굵고 둥글둥글한 귀여운 화살표 한 개 (다른 방향은 코드에서 회전시킨다)
- 연분홍 계열 색, 얇은 진분홍 외곽선, 은은한 하이라이트. 기존 에셋과 어울리는 톤
- 글자 없이 화살표만, 투명 배경 PNG, 가로로 긴 캔버스 가운데
```

## 10. 오븐 타이머 틀

```
기존 디자인 스타일을 유지해서, 오븐 옆에 띄울 "굽기 타이머(게이지) 틀"을 그려줘. 기존 오븐(첨부 oven)과 한 세트처럼 보여야 해.
- 모양은 자유(가로 막대, 반원 게이지 등). 단, 바늘이 처음부터 끝까지 지나가는 트랙이 하나 있어야 해
- 중요: 트랙 안쪽은 아무 색도 칠하지 말고 비워 둬(완전히 투명하게). 빨강·주황·초록 구간은 코드에서 따로 칠한다
- 트랙은 폭이 일정하고 시작점과 끝점이 분명하게 보이게
- 크림색·연분홍 몸체, 둥근 모서리, 기존 오븐과 같은 질감
- 바늘(마커)은 그리지 마. 숫자, 글자, 눈금 숫자 금지
- 투명 배경 PNG
```

## 11. 타이머 바늘(마커)

```
기존 디자인 스타일을 유지해서, 10번 타이머 트랙 위를 움직일 "바늘(마커)" 하나만 따로 그려줘.
- 10번 타이머와 한 세트로 어울리는 색과 질감, 크기는 트랙 폭에 맞게
- 위치가 정확히 읽히도록 끝이 분명한 모양(뾰족한 바늘이나 작은 역삼각형 마커)
- 타이머 틀은 그리지 말고 바늘만, 투명 배경 PNG
```

> 10·11번을 받으면 트랙의 시작점·끝점 위치(이미지 기준 좌표)를 함께 메모해 두면 코드 좌표를 맞추기 쉽다.

## 12~15. 재료가 담긴 그릇 (반죽 단계, 2026-10-29 추가)

지금은 빈 그릇(`empty-bowl.png`, 147×124) 위에 작은 재료 이미지(`flour-pile` 53×38, `cracked-egg` 35×25, `water-splash` 46×25, `butter-cube` 28×28)를 따로 겹쳐 그린다. 크기와 해상도가 그릇과 맞지 않아 어색하다는 사용자 피드백이 있어서, **그릇까지 포함한 한 장짜리 이미지**로 다시 받는다. 받으면 코드는 단계마다 그릇 이미지만 바꿔 끼운다.

- 첨부: `originals/empty-bowl.png`(빈 그릇), `originals/dough-bowl.png`(반죽 담긴 그릇)
- 네 장 모두 같은 대화에서 연달아 만든다. 그릇은 첨부한 빈 그릇과 **모양·크기·위치·시점이 완전히 같아야** 한다(교체할 때 그릇이 튀지 않게).
- 표시 시점(순서: 밀가루 → 계란 → 섞기 → 버터 → 물 → 섞기): 12번 = 계란 넣는 단계, 13번 = 첫 번째 섞기, 14번 = 물 넣는 단계(버터를 넣은 뒤), 15번 = 두 번째 섞기.

### 12. 밀가루가 담긴 그릇

```
기존 디자인 스타일을 유지해서, 첨부한 빈 그릇에 "밀가루"를 부어 놓은 모습을 그려줘.
- 그릇은 첨부한 빈 그릇과 모양, 크기, 위치, 시점, 색(분홍 띠, 하트)을 완전히 똑같이 유지하고, 안에 내용물만 추가
- 밀가루는 그릇 안 가운데에 소복하게 쌓인 하얀 가루 더미. 그릇 입구 안쪽에 보이도록, 그릇 크기에 자연스럽게 어울리는 양
- 가루 질감은 부드럽게, 주변에 약간 흩날린 가루 정도만
- 첨부한 반죽 담긴 그릇처럼, 내용물이 그릇 안에 담긴 느낌(그릇 위에 붙여 넣은 스티커처럼 보이지 않게)
- 투명 배경 PNG, 캔버스 크기와 그릇 위치는 첨부한 빈 그릇 이미지와 동일
```

### 13. 밀가루 + 깬 계란이 담긴 그릇

```
기존 디자인 스타일을 유지해서, 12번 그릇의 밀가루 위에 "깬 계란 하나"를 올린 모습을 그려줘.
- 12번과 그릇, 밀가루 더미의 모양·크기·위치를 완전히 같게 하고 계란만 추가
- 노른자가 동그랗게 살아 있는 깬 계란, 흰자는 밀가루 위에 살짝 퍼진 모습. 그릇 크기에 맞는 실제 비율
- 투명 배경 PNG, 캔버스 크기와 그릇 위치는 12번과 동일
```

### 14. 섞은 반죽 + 버터 (2026-10-29 순서 변경 반영)

순서가 **밀가루+계란 섞기 → 버터 → 물**로 바뀌었다. 첫 번째 섞기 뒤 그릇에는 `dough-bowl.png`(반죽 담긴 그릇)가 보이므로, 버터와 물은 그 반죽 위에 더한다.

```
기존 디자인 스타일을 유지해서, 첨부한 "반죽이 담긴 그릇"의 반죽 위에 "버터 한 조각"을 올린 모습을 그려줘.
- 그릇과 반죽은 첨부한 반죽 담긴 그릇 이미지와 모양, 크기, 위치, 시점, 색을 완전히 똑같이 유지하고, 버터만 추가
- 버터는 노란 정육면체 한 조각, 모서리는 살짝 둥글게. 그릇 크기에 맞는 실제 비율(그릇 입구 폭의 1/4 정도)
- 반죽 윗면 가운데에 살짝 눌러 앉은 느낌으로, 버터 아래에 옅은 그림자
- 붙여 넣은 스티커처럼 보이지 않게, 반죽 위에 자연스럽게 올려진 모습
- 투명 배경 PNG, 캔버스 크기와 그릇 위치는 첨부한 반죽 담긴 그릇 이미지와 동일
```

### 15. 섞은 반죽 + 버터 + 물

```
기존 디자인 스타일을 유지해서, 14번 그릇에 "물"을 부은 모습을 그려줘.
- 14번과 그릇, 반죽, 버터의 모양·크기·위치를 완전히 같게 하고 물만 추가
- 반죽과 버터 주변에 막 부어진 맑은 물. 연한 하늘색 투명한 물, 반죽 위를 타고 흐르다 그릇 안쪽 가장자리에 살짝 고인 정도
- 은은한 하이라이트와 작은 물방울 몇 개. 물이 그릇 밖으로 넘치지 않게
- 투명 배경 PNG, 캔버스 크기와 그릇 위치는 14번과 동일
```

> **반영됨(2026-10-29)**: `flour-bowl`·`flour-egg-bowl`·`dough-butter-bowl`·`dough-butter-water-bowl`(147×124, 고해상도 `*-hires.png` 별도)을 단계별 그릇 이미지로 연결했고, 겹쳐 그리던 작은 재료 이미지 4개는 코드에서 뺐다(파일은 남겨 둠).
>
> 원래 계획: 12·13번은 빈 그릇, 14·15번은 반죽 담긴 그릇과 같은 기준으로 잘라 그릇 슬롯에 그대로 교체해 그리고, 지금 겹쳐 그리는 `flourPile`·`crackedEgg`·`waterSplash`·`butterCube`는 그릇 위 표시에서 뺀다.

## 16~18. 게임 배경 — 취소 (2026-10-29)

디자이너 결정으로 배경 이미지는 만들지 않는다. 게임 프레임 배경은 지금처럼 연분홍 단색(`bg-pink-100`)을 유지한다.
