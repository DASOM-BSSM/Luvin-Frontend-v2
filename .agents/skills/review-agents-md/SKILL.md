# AGENTS.md 검토 및 최적화 절차

대상 파일(`AGENTS.md` 또는 `CLAUDE.md`)을 읽고 아래 5가지 기준으로 감사(Audit) 리포트를 작성한다.

## 1. 검토 기준

- **분량 및 토큰 효율성:** 전체 길이가 200줄(약 8KB)을 초과하는지 확인한다. 특정 작업에만 쓰이는 긴 절차는 별도 `SKILL.md`나 `references/` 문서로 분리하도록 제안한다.
- **지침의 구체성:** "깔끔하게 작성해", "모범 사례를 따라라" 같은 모호한 문장을 찾아낸다. 대신 실제 실행 가능한 빌드/테스트 명령어와 구체적인 코드 스타일 규칙으로 바꾸도록 지적한다.
- **경로 및 참조 무결성:** 문서에 명시된 디렉터리 경로, 파일명, 스크립트 명령어가 실제 저장소 구조와 일치하는지 확인해 깨진 참조를 찾아낸다.
- **지침 간 충돌 및 중복:** 파일 내부 또는 다른 설정 파일(`.cursorrules`, `SKILL.md`)과 상충하거나 중복되는 규칙을 검출한다.
- **보안 점검:** API 키, 비밀번호, 내부 비밀 토큰, 하드코딩된 민감 정보가 포함되어 있는지 스캔한다.

## 2. 출력 형식

1. **요약 점수 (100점 만점):** 명확성, 간결성, 정확성 항목별 진단 결과.
2. **치명적 문제 (즉시 수정):** 깨진 경로, 보안 노출, 서로 모순되는 규칙.
3. **개선 제안 (최적화):** `SKILL.md`로 분리할 수 있는 섹션 및 모호한 표현의 구체화 예시.
4. **수정된 초안 (Diff 또는 전체 코드):** 승인 시 바로 적용할 수 있는 개선본 제시.

## 3. 제약 사항

- 사용자 확인 없이 원본 `AGENTS.md` 파일을 임의로 덮어쓰지 않는다.
